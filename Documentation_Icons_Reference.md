# Documentation Icon Classes Reference

This document contains recommended Material Icons for the Documentation page.
Copy and paste these icon class names into Column D (ICON_CLASS) of your "Documentation" sheet.

---

- `description` - Google Docs / Text documents
- `article` - Articles / Long-form content
- `notes` - Notes / Short documents

## 📝 How to Use in Your Spreadsheet

1. Open your spreadsheet and go to the "Documentation" sheet
2. In Column D (ICON_CLASS), type or paste one of the icon names above (without backticks)
3. Example: `description` or `slideshow` or `picture_as_pdf`

**Optional: Create a Data Validation Dropdown**

To create a dropdown menu in Google Sheets:

1. Select all cells in Column D (ICON_CLASS) starting from D2
2. Go to **Data** → **Data validation**
3. Under "Criteria", select **"List of items"**
4. Paste this comma-separated list:

```
description,article,notes,text_snippet,grid_on,table_chart,insert_chart,functions,slideshow,present_to_all,co_present,picture_as_pdf,folder_special,menu_book,library_books,auto_stories,import_contacts,book,school,cast_for_education,quiz,assignment,receipt_long,fact_check,list_alt,ballot,folder,folder_open,folder_shared,topic,videocam,movie,play_circle,image,photo_library,link,insert_link,language,policy,gavel,verified,rule,code,terminal,integration_instructions,api,developer_guide,help,live_help,support,contact_support,info,settings,tune,admin_panel_settings
```

5. Check **"Show dropdown list in cell"**
6. Click **Save**

Now you'll have a dropdown menu with all the documentation icon options!
