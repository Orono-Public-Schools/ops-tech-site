# Home Page Icon Classes Reference

This document contains recommended Material Icons for the Home page cards.
Copy and paste these icon class names into Column D (ICON_CLASS) of your "Home" sheet.

---

## 📋 Setup Instructions for Your "Home" Sheet

### Column Headers (Row 1):

| Column | Header | Description |
|--------|--------|-------------|
| A | PAGE_NAME | Name of the page (e.g., "Tech Department Links") |
| B | PAGE_URL | URL to the page (use `?page=links` or `?page=documentation`) |
| C | DESCRIPTION | Brief description of what's on this page |
| D | ICON_CLASS | Material Icon class name (from list above) |
| E | IMAGE_URL | Optional custom image URL (overrides icon) |

### Example Data (Row 2 & 3):

**Row 2 - Tech Department Links:**
- A2: `Tech Department Links`
- B2: `?page=links`
- C2: `Access all your essential tools and web applications`
- D2: `link`
- E2: *(leave blank or add custom image URL)*

**Row 3 - Documentation:**
- A2: `Documentation`
- B2: `?page=documentation`
- C2: `Browse guides, manuals, and reference materials`
- D2: `menu_book`
- E2: *(leave blank or add custom image URL)*

---

## 🔗 URL Formats for PAGE_URL Column

### Internal Pages (within your web app):
- `?page=links` - Tech Department Links page
- `?page=documentation` - Documentation page
- `?page=home` - Home page (not needed, but possible)

### External URLs:
- `https://example.com` - Any external website
- `https://drive.google.com/...` - Google Drive folder
- `https://sites.google.com/...` - Google Site

The PAGE_URL can be either a relative link within your web app (`?page=something`) or a full external URL.
