## 📝 How to Use in Your Spreadsheet

1. Open your "Tech Dept Link Directory" spreadsheet
2. Go to the "Links" sheet
3. In Column D (ICON_CLASS), simply type or paste one of the icon names above (without backticks)
4. Example: `computer` or `support_agent` or `inventory`

**Optional: Create a Data Validation Dropdown**

To create a dropdown menu in Google Sheets:

1. Select all cells in Column D (ICON_CLASS) starting from D2
2. Go to **Data** → **Data validation**
3. Under "Criteria", select **"List of items"**
4. Paste this comma-separated list:

```
computer,laptop,tablet,phone_iphone,print,scanner,keyboard,mouse,headset,router,memory,developer_board,devices,build,construction,handyman,engineering,settings,tune,dashboard,admin_panel_settings,manage_accounts,inventory,assessment,analytics,insights,monitoring,description,article,menu_book,library_books,assignment,fact_check,receipt_long,note_add,security,lock,vpn_key,verified_user,shield,policy,support_agent,people,person,groups,contact_support,help,live_help,school,cast_for_education,auto_stories,quiz,language,public,wifi,cloud,cloud_upload,cloud_download,dns,storage,folder,source,database,save,backup,troubleshoot,bug_report,error,warning,sync,update,autorenew,email,chat,forum,announcement,notifications,campaign,check_circle,pending,schedule,event,task_alt,done_all,palette,brush,edit,photo,speed,rocket_launch,star,bookmark,flag,confirmation_number,local_activity,warehouse,barcode,qr_code
```

5. Check **"Show dropdown list in cell"**
6. Click **Save**

Now you'll have a nice dropdown menu with all the icon options!
